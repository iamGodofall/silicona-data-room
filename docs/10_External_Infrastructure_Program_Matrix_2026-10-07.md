# SILICONA External Infrastructure & Startup Program Matrix

Status: CONTROLLED
Reviewed: 2026-10-07

## Purpose

This record tracks current external infrastructure routes for SILICONA. Program terms change. Application status is not evidence of acceptance, credits or production capacity.

## Highest-priority routes

### Huawei Cloud Startup Program

Current official program information:
- targets startups established less than five years ago
- minimum $5,000 Huawei Cloud cash-credit voucher after approval
- application path advertises the possibility to apply for up to $150,000
- provides cloud migration and business resources

SILICONA ask:
- CPU and high-memory compute
- object storage
- managed database
- Kubernetes/container execution
- technical architecture support
- semiconductor ecosystem introductions

Reference:
https://startup.huaweicloud.com/intl/en-us/

### AWS Activate

Current official guidance:
- Founders tier: $1,000 AWS Activate Credits
- selected self-funded startups may reach $5,000 over time
- Portfolio tier: up to $200,000 for qualifying provider-backed startups
- additional credits are discussed for qualifying AI startups

SILICONA ask:
- EC2 CPU/high-memory workers
- S3 evidence storage
- RDS PostgreSQL
- ECR
- SQS
- CloudWatch
- GPU capacity when available through approved credits

Reference:
https://aws.amazon.com/aws-startups/learn/applying-for-aws-activate-credits-a-step-by-step-guide/

### Microsoft for Startups

Current official guidance:
- up to $150,000 in Azure credits is advertised
- eligibility includes a privately held, for-profit software product company
- direct applications are available
- investor-network referrals may unlock additional benefits

SILICONA ask:
- Azure compute
- PostgreSQL
- Blob Storage
- container infrastructure
- monitoring
- AI infrastructure

Reference:
https://learn.microsoft.com/en-us/azure/signups/overview

### Cloudflare for Startups

Current official program:
- Tier 3 provides $10,000 for bootstrapped or self-funded startups under $1M raised
- Tier 2 provides up to $100,000 for qualifying partner-backed startups
- Tier 1 provides up to $350,000 for qualifying companies
- credits cover usage-based platform services
- core security and networking features are included without consuming credits

SILICONA ask:
- Workers
- Queues
- R2
- D1 where appropriate
- edge/API protection
- WAF
- DNS
- Zero Trust

Reference:
https://www.cloudflare.com/startups/

### NVIDIA Inception

Current official program:
- free
- no application fee
- no cohort deadline
- requires an incorporated company
- requires at least one developer
- requires a working website
- offers developer resources, preferred pricing, partner offers, cloud-credit opportunities and investor ecosystem access

SILICONA ask:
- accelerated-compute ecosystem access
- GPU partner credits
- AI hardware pricing
- technical guidance
- investor introductions

Reference:
https://www.nvidia.com/en-us/startups/

### DigitalOcean Startups

Current official program:
- credits vary by approved startup
- prioritizes AI-native startups
- applicants need a company website and matching company email
- core startup credits generally exclude GPU Droplets and certain GPU/inference services
- GPU benefits are separately reviewed

SILICONA use:
- control plane
- staging
- development
- low-cost persistent services
- API and evidence services

Current account state:
- no active Droplets
- month-to-date usage: $0
- account has reached the current three-Droplet team limit despite having zero listed Droplets, requiring control-panel resolution before provisioning

Reference:
https://www.digitalocean.com/startups

## Application state vocabulary

PREPARED
Ready for submission.

SUBMITTED
Application submitted.

UNDER REVIEW
Provider has acknowledged or is reviewing.

ACCEPTED
Program acceptance confirmed.

CREDITED
Credits actually issued.

DEPLOYED
Infrastructure actually provisioned.

QUALIFIED
SILICONA workload executed successfully in the target environment.

PRODUCTION
Sustained production workload evidence exists.

No earlier state implies a later state.
