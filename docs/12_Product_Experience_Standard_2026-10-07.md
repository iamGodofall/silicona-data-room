# SILICONA Product Experience Standard

Status: PUBLIC PRODUCT EXPERIENCE REFERENCE
Effective: 2026-10-07

SILICONA presents semiconductor engineering as one continuous workspace.

During a deterministic pipeline run, the workbench follows the active stage automatically. The current stage becomes the primary engineering window while a persistent stage rail shows the complete sequence and progress.

The sequence is:

Specification
Architecture
RTL Generation
RTL Lint
Simulation
Formal Verification
Synthesis
Equivalence Check
Timing Analysis
Power Analysis
Physical Design
GDS Streamout
DRC Check
LVS Check
Engineering Report

Each stage exposes its purpose and evidence basis. AI proposals remain distinct from deterministic EDA results. The interface keeps the doctrine visible:

AI proposes
EDA tools calculate
Verification decides
Engineer approves

Execution transparency is part of the experience. Before hosted work begins, SILICONA shows the execution class and applicable customer-charge basis.

Current rate card:

Standard: $5
Heavy: $25
Physical: $75
Commercial EDA / signoff: $250

During pre-launch open access, the UI shows $0 charged today. After billing activation, the published rate card governs hosted execution. Successful execution captures the reservation. Failed or cancelled execution releases the reservation. Silent overage is not used.

Account usage exposes execution credits used, reserved and available.

GLM / Zhipu AI (Z.ai) remains the deployment default. The current default model is GLM-5.3. Provider and model preferences remain configurable through the platform provider registry, subject to deployment configuration.

The product surface is designed for both individual engineers and enterprise programs. Enterprise controls emphasize evidence provenance, execution identity, deployment boundary, certification state, audit state and explicit commercial EDA boundaries.

Production operation is still subject to the qualification gates documented in the current engineering status record.
